# Personal OS V02

Personal OS V02 is the architectural rebuild of the Personal OS V01 prototype.

## Initial stack

- React
- Vite
- JavaScript
- Supabase (dependency installed, integration not yet configured)

## Current phase

Foundation only.

The application intentionally starts small. Features from V01 will be reimplemented incrementally after the architecture is established.

## Local development

```bash
npm install
npm run dev
```

Do not add real Supabase credentials to source files. Environment variables will be introduced when the Supabase integration phase begins.
